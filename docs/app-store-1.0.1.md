# App Store text for 1.0.1

1.0's listing and App Review notes describe the old free tier (a weekly AI
trip, a free wallet, free trip sharing). 1.0.1 changes what Pro includes, so
both need updating **before 1.0.1 is submitted for review** — a listing that
promises a free feature the app gates is a guideline 2.3.1 rejection.

## What changed (for your reference)

| | Free | Pro |
|---|---|---|
| AI trips | 1 a month, single city | Multi-city, effectively unlimited (fair use) |
| Travel together (invites, shared budget, packing list) | — | ✓ |
| Wallet | 2 items, entered by hand | Unlimited, AI import from confirmations |
| Flight alerts | — | ✓ |
| Trips, maps, flyover, feed, globe, search, messages | ✓ | ✓ |

## App Store description

Wherever the description presents the wallet, trip sharing or AI trips as
free, qualify them. Suggested paragraph for the Pro section:

> **Supernova Pro** — unlimited AI itineraries, including multi-city trips
> across several countries; plan together with friends, with a shared budget
> and packing list; keep every boarding pass, reservation and loyalty card in
> one wallet and import bookings straight from your confirmation emails; and
> get live alerts when your flight boards, lands or changes.
